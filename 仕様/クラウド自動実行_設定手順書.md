# `run_daily_forecast_occto_v4.ps1` クラウド毎日自動実行 運用仕様書（追加課金 0円・構築完了版）

## 1. 全体アーキテクチャ（毎日自動実行の流れ）

1. **毎朝 09:00 JST：GitHub Actions によるクラウド自動予測（本番環境）**
   - リポジトリ: `https://github.com/koichinn/areaprice2-forecast`
   - ワークフロー定義: [`.github/workflows/daily_forecast.yml`](file:///P:/エリアプライス2/.github/workflows/daily_forecast.yml)（`cron: '0 0 * * *'`）
   - クラウド上の仮想 Windows サーバーで `P:\エリアプライス2` をマウントし、GitHub リポジトリ上の最新プログラム（`学習/predict_system_day1_occto.py` 等の `v4_sub2_super` モデル）をオーバーレイ適用した上で [`学習/run_daily_forecast_occto_v4.ps1`](file:///P:/エリアプライス2/学習/run_daily_forecast_occto_v4.ps1) を自動実行します。
   - 実行完了後、以下の最新予測CSVを GitHub リポジトリにコミットし、次回用のマスタデータ＋最新コード（`cloud_release_bundle.zip`）も `latest-data` リリースへ自動保存します：
     - `予測/forecast_system_day1_occto_latest.csv`（システムプライス DAY1 `v4_sub2_super` 予測：6-Fold Walk-Forward MAE `1.9991`）
     - `予測/forecast_day1_to_day7_latest.csv`（システム＋9エリア DAY1〜DAY7 予測）
     - `予測/system_day1_compare_daily.csv`（システムプライス日次精度比較）

2. **毎朝 09:30 JST：Power Automate による OneDrive 自動同期**
   - フロー名: `毎日実行_エリアプライス2予測同期`（スケジュール済みクラウド フロー、1日1回 09:30 AM）
   - 標準（無料）コネクタ `OneDrive for Business`「URL からファイルをアップロードする」により、GitHub 上の最新予測CSV 2ファイルをローカル同期対象の OneDrive（[`P:\エリアプライス2\予測`](file:///P:/エリアプライス2/予測)）へ自動保存します：
     - `https://raw.githubusercontent.com/koichinn/areaprice2-forecast/main/%E4%BA%88%E6%B8%AC/forecast_system_day1_occto_latest.csv`
       → `/ドキュメント/program/エリアプライス2/予測/forecast_system_day1_occto_latest.csv`
     - `https://raw.githubusercontent.com/koichinn/areaprice2-forecast/main/%E4%BA%88%E6%B8%AC/forecast_day1_to_day7_latest.csv`
       → `/ドキュメント/program/エリアプライス2/予測/forecast_day1_to_day7_latest.csv`

3. **随時（11時前・11時以降いつでも）：ダッシュボードの起動と最新表示**
   - 実行スクリプト: [`P:\エリアプライス2\web\run_accuracy_dashboard_web.ps1`](file:///P:/エリアプライス2/web/run_accuracy_dashboard_web.ps1)
   - 起動時に最新の JEPX スポット約定実績を取得し、OneDrive に同期済みの `P:\エリアプライス2\予測\forecast_day1_to_day7_latest.csv` と結合して [`P:\エリアプライス2\web\forecast_accuracy_dashboard.html`](file:///P:/エリアプライス2/web/forecast_accuracy_dashboard.html) を生成・表示します。

## 2. 予測プログラム更改時の本番（GitHub）反映ルール

- **本番環境の位置づけ**:
  - 予測の本番環境は GitHub リポジトリ（`https://github.com/koichinn/areaprice2-forecast`）です。
  - ローカルの `P:\エリアプライス2` で予測プログラムや較正設定（`学習/*.py`, `学習/*.json`, `学習/*.ps1`, `web/*.py` 等）を更改した際は、**必ず GitHub リポジトリ上の対応ファイルも同時更新（コミット）** します。
  - [`.github/workflows/daily_forecast.yml`](file:///P:/エリアプライス2/.github/workflows/daily_forecast.yml) の Step 4 にて、`cloud_release_bundle.zip` 展開後にリポジトリ内の最新コード（`学習/`, `web/`, `database/` 等）を上書きコピーしてから予測を実行し、Step 9 で `cloud_release_bundle.zip` 自体も最新コード入りで再パッケージして `latest-data` リリースを更新するため、リポジトリ上のコードを更新するだけで翌朝 09:00 の実行から自動的に最新プログラムが適用されます。

## 3. 手動で即時実行したい場合

- **クラウド予測を手動で今すぐ回したいとき**:
  1. `https://github.com/koichinn/areaprice2-forecast/actions` を開きます。
  2. 左側の **「JEPX Daily Forecast (AreaPrice2)」** をクリックし、右側の **「Run workflow」** → 緑色の **「Run workflow」** を押します。
- **OneDrive への取り込みを手動で今すぐ行いたいとき**:
  1. Power Automate のマイフローから `毎日実行_エリアプライス2予測同期` の **「実行」**（または編集画面の「テスト」）を押します。
